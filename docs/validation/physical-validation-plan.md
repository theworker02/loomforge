# Physical validation plan — proposed, not performed

The first experiment isolates the riskiest mechanism: guided insertion and seating of the selected Mini-Fit Jr terminal/housing. Required parts: 30+ `39-01-2040` housings, >=120 supplier-qualified `39-00-0038` pre-crimped 22 AWG leads, a manually actuated force/displacement rig or instrumented Z axis, interchangeable guide prototypes, microscope, manufacturer-approved extraction tooling, and a controlled mating/test breakout.

| Test | Proposed sample / criterion | Evidence |
|---|---|---|
| Alignment repeatability | 30 approach cycles; <=0.10 mm target at guide datum | dial/vision measurements |
| Insertion / visible damage | >=30 inserts across guide variants; zero visible terminal/housing damage target | photos, microscope log |
| Seating correlation | 30 inserts; correlate force/travel threshold with approved inspection and destructive/sample retention method | raw traces and inspection table |
| Fault detection | 10 deliberate faults per critical class; target 100% detection in controlled set | scenarios/results |
| Continuity mapping | 20 known-good and faulted fixtures; detect open/mis-map/short | measurement records |
| Safety controls | qualified review plus repeated E-stop/door/power-loss trials | signed test record |
| Endurance/changeover | not before insertion validation; establish sample size from failure mode data | future plan |

These are engineering targets, not reliability claims. Define acceptance after supplier documentation review and risk assessment. Never use synthetic force traces as trial evidence.
