# Product definition

LoomForge is a supervised, local-first modular bench workstation for assembling one connector housing from operator-presented pre-crimped wires, then verifying connectivity through a defined mating and far-end test interface. It targets prototype and small-batch teams. It excludes cutting, stripping, crimping, bin picking, arbitrary connectors, high-voltage tests, unattended operation, vehicle/aircraft connection, production certification, and aerospace certification.

Simulation is a distinct adapter and is visibly designated in UI/reports. A missing physical controller is a fault—not permission to simulate.
