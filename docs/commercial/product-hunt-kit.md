# Product Hunt / public demo kit

## Product description

LoomForge is a development engineering package for a proposed supervised workstation that guides pre-crimped terminals into a selected connector family, records the assembly path, and checks expected electrical mapping. The interactive demo lets reviewers walk through the proposed LF-P1-R02 operating sequence and introduce representative simulated faults.

## Media

- `site/media/product-hunt-cover.png` - 1200 x 630 simulated-demo cover.
- `site/media/loomforge-simulated-walkthrough.gif` - assembly walkthrough.

Every asset is labelled simulated/development design. It must not be presented as footage of an operating machine, measured force data, production performance, certification, or customer deployment.

## Suggested launch copy

**Tagline:** A traceable, small-batch connector-assembly workstation design.

**First comment:** LoomForge is not a machine for sale. It is a plans-and-software engineering package for manufacturers or machine builders to review, fabricate, safeguard, calibrate, and validate for their own use. The public demo models the proposed operator workflow and fault handling; it does not control hardware.

## Loom upload

The GIF walkthrough can be uploaded directly where animated media is accepted. A narrated Loom recording should be captured from `site/demo.html` while stepping through successful and faulted paths, and should open with the simulation/development-design disclosure.
