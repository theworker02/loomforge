# Design package contents

The downloadable engineering package contains: source CAD concept, BOM, electrical architecture/I-O schedule, calculation source, simulation backend/UI, recipe examples and validation tests, research/source register, system/safety/control documentation, manufacturing handoff documents, validation plan, and simulation report examples.

Use it to review design intent, export/regenerate available artifacts, evaluate compatibility, plan procurement/fabrication, assemble/commission under manufacturer control, and record manufacturer-led validation. It is not an order form or offer for an assembled machine.
