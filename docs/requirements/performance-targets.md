# Proposed performance targets and verification

| Target | Basis | Classification | Required physical verification |
|---|---|---|---|
| 4-cavity selected family only | scope control | requirement | recipe/fixture tests |
| insertion limit <=15 N | Molex PS-5556-002 | sourced limit | exact part/application confirmation |
| <=0.10 mm head repeatability | guide alignment need | proposed | 30-cycle metrology |
| 0–50 N force sensing | 15 N process plus margin | proposed | calibration/noise/overload test |
| <=12 mm unsupported lead | buckling risk control | assumed | worst-case wire study |
| 60 s four-wire cycle | calculation | calculated | timed trial |
| fixture changeover <=5 min | small-batch goal | proposed | 10 operator trials |

Microstep resolution is not positioning accuracy. No calculated or simulated target has been accepted as demonstrated performance.
