# M1 cost and capacity framework — proposed 12-unit pilot

No supplier quotations or savings claims are included. This framework makes the receiving manufacturer’s estimate auditable.

| Cost bucket | Required estimate inputs | Capture separately? | Notes |
|---|---|---|---|
| Purchased components | unit price, MOQ, lead time, freight, tax, currency/date | yes | distinguish prototype and recurring quantities |
| Custom machined parts | material, setup, cycle time, inspection, finish | yes | quote one-off, first article, and 12-unit breaks |
| Sheet/guard parts | material, bends, tooling/NRE, finish, guarding material | yes | require flat-pattern assumptions |
| Additive parts | material, machine time, post-process, replacements | yes | prototype-only unless requalified |
| Electrical build | cables, labels, terminals, enclosure hardware, labor | yes | do not omit safety hardware or test fixture |
| Labor and calibration | build hours, inspection, alignment, software setup, test | yes | track actual M1 hours by unit/operation |
| Quality / rework | FAI, NCR, scrap, rework, retained samples | yes | essential for M2 decision |

## Proposed capacity observations

Record queue time, touch time, rework time, and blocked time for every M1 build step. Report median and range only after physical builds. Do not extrapolate a pilot cycle time, cost per completed assembly, or return on investment from simulation.
