# Responsibility boundaries

LoomForge deliverable: consistent reviewable files; documented assumptions/calculations; software and available test evidence; proposed assembly/verification guidance; known hazards/limits/unresolved issues.

Receiving manufacturer or appointed builder: independent intended-use review; sourcing/substitution review; fabrication/assembly; safeguarding implementation/validation; calibration/physical testing; applicable compliance assessment; operator training; maintenance; and approval for its production environment. This allocation is a scope statement, not a statement eliminating any designer legal responsibility.
