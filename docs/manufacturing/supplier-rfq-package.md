# Supplier RFQ package - SC-A0 / M1

## RFQ cover text

Request quotation for prototype-only parts supporting a proposed 12-unit LoomForge M1 manufacturer pilot. Quote material, process, finish, NRE/tooling, unit price at 1/12/15 quantities, lead time, minimum order, inspection capability, payment terms, shipping assumptions, and exceptions. This RFQ does not authorize production or represent a purchase order.

## Package contents per supplier

| Supplier scope | Required attachment / information | Current release state |
|---|---|---|
| Sheet metal | part register, R02 envelope, finish intent, pending released flat patterns | quote budgetary only; fabricator must verify bends/flat pattern |
| Precision machining | part register, datum intent, critical interface sketch, inspection request | guide/fixture critical dimensions blocked pending controlled connector data |
| Motion/electrical/safety | required function, environmental/site assumptions, interface drawing, approval criteria | select after responsible-engineer review |
| Connector/test components | exact manufacturer part numbers and controlled document revision | authorized-source confirmation required |
| Prototype additive | tray/comb part IDs, ESD/material requirement, fit-check intent | prototype-only parts, not permanent wear release |

## Supplier response requirements

1. Identify every assumption, deviation, unavailable feature, and outside process.
2. Confirm material, thickness, finish, heat treatment, and inspection method where applicable.
3. State drawing revision used; do not quote an uncontrolled PDF as released production data.
4. Identify any supplied-component lead-time or lifecycle risk.
5. Do not make safety/compliance claims on behalf of LoomForge.

## Explicit exclusions

No supplier may infer authorization for final manufacturing, installation, commissioning, guard certification, electrical certification, terminal-process qualification, or public claims from this RFQ package.
