# LF-P1-R02 proposed assembly order

1. Fabricate/inspect plinth, spine, supports and console; establish base/fixture datums.
2. Install feet, rear spine and side supports while rear/side tool access is open.
3. Mount rails, X/Y/Z stages, force mount, cable chain, gripper/guide; align with metrology artifact before guard installation.
4. Install electronics tray, fused power distribution, safety hardware and rear service panel; complete electrical checks under responsible engineer control.
5. Install camera, work/vision lighting, status guide and separate harnesses along spine.
6. Install tray, combs, fixture cartridge/test plug and verify forward extraction clearance.
7. Install transparent guard, hinge/stays/interlock and console/E-stop; prove no collision over 105 degree sweep.
8. Calibrate, conduct low-energy motion/guard tests, then guided insertion trials.

Required tools include torque tools, alignment indicator/fixture artifact, electrical safety test equipment, load-cell calibration reference, camera target, and manufacturer-approved terminal inspection/rework tools. This sequence is geometry-reviewed only at conceptual level; no physical assembly was performed.
