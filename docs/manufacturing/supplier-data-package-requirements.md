# Supplier data-package requirements — SC-A0

**Document:** LF-SCM-002 · **Revision:** A0 (proposed)

Attach the applicable requirements below to each RFQ. A supplier response missing a requested item is incomplete, not automatically unacceptable; the receiving manufacturer decides disposition.

| Package | Required submission | Special review |
|---|---|---|
| Precision machined components | quote, material/finish, process route, critical-feature inspection proposal, lead time, revision acknowledgement, assumptions | datum/guide/fixture interfaces and deburring |
| Sheet-metal and panels | quote, material thickness, bend radius/K-factor, flat-pattern exceptions, finish, tooling/NRE, first-article plan | door/guard/interlock interfaces; fabricator flat-pattern verification |
| Guard material/assembly | material data, thickness, edge/fastener concept, cleaning limits, mounting proposal | manufacturer safeguarding authority must review; no compliance assertion requested from LoomForge |
| Motion components | exact P/N, lifecycle/availability, data sheets, load/travel compatibility, alternatives | no unreviewed actuator or guide substitute |
| Electrical/safety components | exact P/N, ratings, certificates/datasheets as applicable, availability, wiring-build assumptions | protective-function architecture and validation remain manufacturer-owned |
| Connector/test-interface components | exact P/N, drawing revision, lot/packaging, compatible wire/terminal confirmation, application guidance | no connector/terminal substitution without fixture and test review |
| Additive prototype parts | material, build orientation, post-process, dimensional capability, cleanability, ESD statement if applicable | prototype-only unless an approved later process is defined |

## Quote normalization fields

Require currency, quote validity, unit-price breaks (1/2/12 plus spares if applicable), NRE/tooling, setup, inspection, lead-time definition, shipping terms, payment terms, exclusions, and revision identifier. Do not compare quotes that use different configuration assumptions without recording the difference.
