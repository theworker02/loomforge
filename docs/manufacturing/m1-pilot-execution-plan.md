# Proposed M1 pilot execution plan — 12 units

**Document:** LF-MFG-PLN-002 · **Revision:** A0 (proposed)

## Sequenced build strategy

| Wave | Units | Entry criteria | Primary learning objective | Exit decision |
|---|---|---|---|---|
| 0 — readiness | none | SC-A0 review, critical supplier inputs, controlled traveler and inspection assets | ensure an evidence path exists | authorize M1-001 only |
| 1 — first articles | M1-001, M1-002 | FAI plan and critical components received | fit, access, assembly sequence, cable routes, guide/fixture interfaces | correct drawings/DFM before powered work |
| 2 — technical validation | M1-003 to M1-006 | safety architecture reviewed; calibration/test fixture available | controlled insertion, force/seating correlation, electrical fault matrix | authorize limited workflow studies or hold |
| 3 — workflow learning | M1-007 to M1-010 | wave-2 findings incorporated under change control | loading, changeover, intervention, service observations | propose M2 changes; no production conclusion |
| 4 — references | M1-011, M1-012 | chosen pilot configuration frozen | retain known configuration for regression/service comparison | archive as-built records |

## Daily control meeting inputs

- Units and traveler step status; stops are visible and never hidden as “in progress.”
- New substitutions, deviations, NCRs, safety concerns, or software/recipe changes.
- Open DFM risks and owner/date for the next evidence action.
- Calibration state and test-fixture health.
- Actual build hours and blocked time, labelled as pilot observations only.

## M1 completion review

M1 ends in a decision record: continue with a revised development build, repeat a targeted study, redesign, or stop. A count of twelve assembled units is not by itself a pass criterion.
